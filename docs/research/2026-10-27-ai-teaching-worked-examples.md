# 两段 AI 教学设计样例与诊断案例

日期：2026-10-27。研究参考，不是正式地图、模型实跑结果或真实学习者记录。与 [研究方案](2026-10-27-ai-teaching-research.md) 配套。数学例子为本次自编并提供推导；公共空间材料为显式虚构，用于训练证据辨析。外部来源只支持注明的知识或方法，不为本方案学习效果背书。

## A. 数学：为什么两个极限存在还不能直接复合

### 目标与范围

使用者希望能判断复合极限何时可以直接计算，并识别把极限值和点值混淆的推理。必要背景是函数取值、复合函数和去心极限；不清楚时就地补讲，不强制先学整章。初次学习不要求 epsilon-delta 证明。来源：OpenStax Calculus Volume 1，[2.4 节定理 2.9](https://openstax.org/books/calculus-volume-1/pages/2-4-continuity) 给出外层在内层极限点连续时的复合函数极限定理。

### 可供 AI 规划参考的完整短路线

| 入口 | 处理的问题 | 必要衔接 | 可提供的活动 |
| --- | --- | --- | --- |
| A1 点值与附近趋势 | F(0) 与 lim F(t) 为什么可以不同 | 函数取值，可即时补讲 | 对比几个取值和一个定义 |
| A2 连续时的复合 | 哪个条件让代入极限可靠 | A1 中的区别与复合函数含义 | 示范连续外层，再选一例解释条件 |
| A3 外层不连续时 | 内层实际会不会把输入送到特殊点 | A1；需要比较 A2 的适用条件 | 同一外层搭配两个内层，对比结果 |
| A4 解释边界 | 为什么“某组充分条件”不是每个成功个例的必要条件 | A2、A3 的例子 | 比较不同理由，按需保存自己的条件说明 |

表中是设计依赖解释，不自动写数据库边。用户可直接问 A3，系统先补必要解释；正式路线仍由产品 AI 规划和用户确认。本样例不是完整微积分课程。

### 核心依据与可检查结论

已知 g(x)→L，若 F 在 L 连续，且复合函数在所讨论趋近范围内有定义，则 F(g(x))→F(L)。这是来源中的连续外层情形。

自编反例：F(t)=1（t≠0），F(0)=2。

| 内层 | x→0 时内层极限 | x≠0 时复合函数 | 复合极限 |
| --- | --- | --- | --- |
| g(x)=0 | 0 | F(0)=2 | 2 |
| g(x)=x² | 0 | x²>0，故 F(x²)=1 | 1 |

两种情形中，外层去心极限 lim(t→0)F(t) 均为 1。第一行直接反驳“两个极限存在就一定能按外层去心极限复合”。第二行不能把已经排除的 x=0 算进去。

另一个正例：F 恒等于 1、g 恒等于 0，复合极限仍是 1。它反驳“所有成立的个例都要求 g 在去心邻域不取 0”。不要把足以保证一般结论的一组条件写成每个成功个例都必须满足的条件。

若需一般的非连续外层说明：F(t)→A（t→L），g(x)→L（x→a），并且在足够小的去心邻域内 g(x)≠L、F(g(x)) 有定义，则 F(g(x))→A。这里给的是充分条件组。证明思路是：由外层极限选取 0<|t−L|<η，由内层极限得到 |g(x)−L|<η，额外的不等条件补足左边的严格正值。此段是可检查推导，不冒充 OpenStax 对非连续外层情形的原话。

### 两种困难，两个不同回应

示意输入一：“g(x) 趋近 0，所以我把 F(0)=2 当成所有复合极限。”

建议回应：先认可其在 g 恒为 0 的例子里算对，再对比 g=x²。取 x=0.1 时，真正送进 F 的是 0.01；只要 x≠0，输入都不是 0。因此这一个复合函数在去心邻域恒为 1。可以邀请其比较第二个 x，或直接展示完整说明。

示意输入二：“既然不取 0 就能得到 1，那么任何成功例子都必须不取 0。”

建议回应：直接给 F 恒为 1、g 恒为 0 的例子，说明当前问题已变成“是否所有成功例子都满足这个条件”。用一个成功但不满足条件的例子，就能否定其必要性断言。无需重复第一种困难的取值教学。

如果用户只说“我不懂”，先问卡在函数取值还是极限含义，也可提供短示范。不直接诊断为量词错误。用户要求看完整解答时可以展示，不以拒绝答案来维持所谓苏格拉底教学。

示意输入三：系统错误地说第一行的复合极限为1，用户反驳：“但g恒为0，送进F的不是一直是0吗？”

建议回应：先检查用户指出的实际代入，确认F(g(x))=F(0)=2；明确撤回先前的错误结论，并说明混淆了外层去心极限与点值。保留用户原回应与错误参考版本，按现有局部更正规则修订；不能把用户的正确反驳当作“仍不理解极限”，也不能只改表面答案而保留错误评价依据。若一时不能核清，保留争议并停止依赖该参考评分。

### 观察与个人记录

可以观察其能否解释两个内层为什么造成不同结果。用户可保存“我目前理解为……”或仍未解的疑问，不能因为答错而禁止保存。若要测独立运用，使用未在教学中曝光、但检查相同判断的任务；下面公开案例不是隐藏测验。

## B. 开放探索：座椅是否让公共空间更有活力

### 目标与来源

目标是形成可解释的观察与比较，而不是得出唯一城市设计答案。Gehl Institute 的 [Public Life Data Protocol](https://github.com/gehl-institute/pldp) 提供记录公共空间中移动、停留等活动的方法。协议支持观察记录，不直接证明“座椅导致活力提高”。

研究示意材料，全部虚构：空间甲在工作日中午观察 20 分钟，有 40 人经过、12 人停留；空间乙在周末傍晚观察 20 分钟，有 25 人经过、16 人停留。甲座椅较少，乙座椅较多；没有记录天气、活动或附近设施。不能把这些数据当作实地调查结果。

### AI 可据此规划的探索路线

1. 讨论“活力”在此处指什么：人流、停留、交往或不同人群的可使用性，允许多个维度和价值取舍。
2. 从材料中分开观察、计算和解释；例如可以报告观察到的停留人数，但不能把“停留人数/经过人数”直接解释成每个行人的停留概率，因为计数对象未必相同。
3. 比较座椅、时段、天气、周边用途等替代解释，提出下一次需要补充什么观察。
4. 形成一个有条件的判断与待解问题，用户自行决定是否保存或联系其他记录。

这些可以合并为一次讨论，也可以按兴趣展开；没有每步必答或统一分数。

### 分支反馈示意

- 用户：“乙停留的人更多，证明多放座椅就有效。”——指出材料确实显示这次观察乙停留人数更多，但时间与场景不同，尚不能排除其他解释。可一起设计更可比较的观察，不能直接嘲讽“你不懂因果”。
- 用户：“这些数据不能证明因果，所以完全没有意义。”——解释描述性证据仍能提出问题和指导下一轮观察，区别“提供线索”和“足以证明”。
- 用户：“我更关心老人能不能舒适使用。”——调整探索焦点到其用途与需要的资料，而不是强迫回到最大化人流量。

### 可观察的改善与边界

较好的表现包括：说明“活力”的含义、准确使用材料、区分观察与解释、提出可能改变判断的新证据。不同立场都可能合理。AI 不能因用户没有选择它偏好的设计方案而判错。若找不到可靠外部判断，保留论证和不确定性，不制造一个虚假的权威总分。

## C. 审查器校准用公开案例

本表是有依据的研究者参考标注，数学部分含可核验推导；教学选择仍是待检验的设计。它不是已获专家全面确认的金标准，更不是未见测试集。后续正式实验须另备不进入调优的任务。

| 编号 | 待检查的输出/行为 | 预期判断及理由 |
| --- | --- | --- |
| M1 | 上述不连续 F 与 g=0 的复合极限是 1 | 确定计算错误；实际恒为 2 |
| M2 | 上述 F 与 g=x² 的复合极限是 1，因为 x≠0 时 x²≠0 | 这段推导正确，不应误拦 |
| M3 | g=x² 在 x→0 的去心邻域仍取到 x=0，所以复合极限受 F(0)影响 | 确定范围错误；排除了 x=0 |
| M4 | 所有成功复合都必须 g(x)≠L | 确定全称错误；F恒1、g恒0反驳 |
| M5 | 仅已知 lim(t→0)F(t)=1，就说所有 t≠0 都有 F(t)=1 | 确定推理错误；F(t)=1+t 是反例 |
| M6 | 把 (H且非C)→C 说成恒假或与 H→C 真值不同 | 确定逻辑错误；两式都等价 非H或C；但角色还原是否忠实仍需另查 |
| S1 | 来源只给连续外层定理，却归因成“来源证明两个极限存在即可” | 来源不支持该主张；存在真实URL不能解错 |
| R1 | 为方便教学推荐先A再B，同时声明不是必要前置 | 教学选择，不应仅因非唯一最佳而阻断 |
| R2 | 原来明确选学的内容，在新任务中成为所有人必须完成的前置 | 检查实际范围与责任冲突；不能靠标题猜测 |
| R3 | 已声明某拓展选学，却规定所有人都必须完成它才能进入原主线 | 范围责任冲突；不能靠仍写着“选学”消除真实强制 |
| R4 | 用户明确选择了选学主题，系统说明完成该主题需要一项相关活动 | 不因有完成要求就判成主线强制；检查要求是否只作用于用户选择的主题 |
| L1 | 用户只说不懂，就永久记录其“逻辑能力弱” | 无依据的稳定标签，不能由一次表现推出 |
| L2 | 用户明确要求完整解答，系统持续反问且不能跳过 | 不符合本项目帮助与自主选择要求；不等于所有提问式教学无效 |
| L3 | 用户正确指出参考把F(0)=2误作1，系统仍按错误参考继续判用户错 | 应先核对并纠正参考，撤回误判；参考并非不可质疑的真值 |
| O1 | 用不同日期、时段的虚构观察宣布座椅产生了因果效果 | 证据不足；应降为待检验解释 |
| O2 | 用户给出有材料支持的不同规划偏好，因不同意AI而判错 | 评价对象错误；应比较论证与取舍 |
| O3 | 两种观察得到不同描述，明确条件后都保留 | 合理处理不确定性，不应强求同一结论 |

评估时必须同时包含正确例和错误例。只看查出了多少错误会鼓励误判；只看通过率会掩盖漏判。程序性修复（更正保存、引用身份等）沿用现有回归证据，不在此用教学样例假装重复证明。
