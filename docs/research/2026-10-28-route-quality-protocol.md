# 路线质量的迁移与完整服务验证

日期：2026-10-28。对应原目标：研究出解决路线、知识设计与教学反馈难点的可行办法。这个协议不把局部核对命中率等同于路线质量，也不以固定节点数或教学顺序偏好定义通过。

## 两类证据分别回答什么

第一类是新构造的六组成对知识文本。每组保留相同目标和背景，只改变一个实质条件或结论；被测模型每次只见一个案例。判据来自代数证明、有限反例、实际执行及精确计数，单独保存，不进入提示。使用当前生产规划知识核对的提示与返回合同，比较同一输入在关闭和开启推理时的首份报告，以及局部更正是否保留原目标、题设与正确条件。两臂只改变运行模式，实际请求体另行比对；提供方的推理模式忽略 temperature，不能称有效采样参数完全相同。

这些文本没有参与此前提示调整，但由研究者选择并审读，属于新的迁移诊断样例，不是随机抽样、独立人类认证的保留集。仅用最小候选包装进入知识核对器，不具备正式路线创建资格。报告字段完整、局部替换可应用、结论正确、理由可靠和新内容没有错误须分别检查。原输入及推导见[病例](../../web/scripts/research/planning-transfer-cases.json)和[判据](../../web/scripts/research/planning-transfer-oracle.json)；每次调用前冻结文件与模块指纹，失败不自动补抽样。

第二类使用实际课程和路线请求处理器，连续经过课程研究、范围批判、知识核对、骨架生成、阶段逐个展开、必要修复、保存及重载。两个研究目标分别是有限筛查表的条件概率与 Python 列表的引用/拷贝；均包含明确的已有基础、主线内容与选学边界。所有路线由 AI 规划，研究材料只提供可核对的知识与目标，不提供人工骨架。

每个目标分别运行两个模式，总计四条独立生成路线。初始课程的联网接口未编码这一模式开关，因此记录每次实际接口和模式，不假称每个调用都完成了模式切换。两条路线的实际产物也不会逐字相同，结果是小样本系统比较，不能从中分离所有因果贡献。

## 完整路线的检查对象

- 知识结论：条件方向、数值计算、程序执行和解释是否对应实际给定条件。
- 目标覆盖：已完成的骨架与阶段是否实际承接目标任务，而不只是出现标题或登记 ID。
- 选学边界：代数推导和深入拷贝等选学项不能成为主线的强制要求或前置。
- 基础与来源：学习者自述不是测验结果；研究者材料、取得的来源正文和模型推导保持区别。
- 前置关系：具体任务是否确实需要某项理解或操作；推荐顺序不自动成为逻辑必要关系。
- 任务可执行性：实际例子、输入、背景与任务之间能否接续，不规定一概念一节点。
- 教学取舍：允许多种合理安排。没有实际学习者表现时，不能仅凭模型偏好宣布哪种顺序最有效。

每个发现须引用真实运行、JSON 路径和最小足够原文，并给出独立依据；已生成且缺少责任与尚未生成而无法观察分别记录。完整判据及预先运行的有限计算见[路线评价依据](../../web/scripts/research/route-quality-oracle.json)。Python 材料按[官方拷贝文档](https://docs.python.org/3/library/copy.html)整理，固定代码另在本机运行；不会执行模型新生成的任意程序。

## 运行与结论边界

每条路线最多二十四次实际模型请求，整个实验最多九十六次；正式服务内部原有修复限制不变。这个上限是研究预算，不是新增产品门禁。任何实际错误、阻断或不可用回执停止该路线，保留已到达的产物，不绕过门禁继续展开。课程入口可能把内层错误包装在 HTTP 200 中，因此同时核对响应内容，不能只看状态码。

使用版本化空白 seed 的隔离副本、临时 Electron 设置和独立进程。先核验 SQLite 实际连接路径再运行；所有阶段只产生候选，不模拟正式用户确认，不创建正式节点。实际设置哈希、代码指纹、每次原请求、原回应、报告、保存内容和失败均留存；结束删除临时设置，原用户数据不参与实验。

脚本完成仅表示预定研究流程已停止或收集完毕。某条路线只有在全部实际 Stage 候选展开并重载后，才可称候选设计链到达；其语义质量仍需逐项审读。模型审查、自动化通过和研究者审读都不等于真实学习增益、长期保持或对任意领域的质量保证。实际结果与未完成范围集中记录在[当前状态](../../CURRENT_PROGRESS_AND_DIFFICULTIES.md)。
