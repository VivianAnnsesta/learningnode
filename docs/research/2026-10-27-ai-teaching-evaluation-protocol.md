# EnglishNode 教学方案的比较与评价协议

日期：2026-10-27。状态：可执行研究设计，尚未运行真实模型对照或学习者实验。配套 [主报告](2026-10-27-ai-teaching-research.md)、[公开案例](2026-10-27-ai-teaching-worked-examples.md)。不新增产品准入门、掌握分数或正式状态。

## 1. 要回答的问题

1. 路线是否准确承接原目标，关键基础是否有实际用途，是否保留声明的取舍？
2. 改进当前问题的材料输入，能否减少条件遗漏、错误归因和参考解答错误？
3. 根据具体困难选择帮助，是否比当前方式更相关、更容易接手？
4. 在明确的帮助条件下，学习者的解释、独立尝试与后续运用有没有改善？
5. 改善是否值得其额外等待、调用费用和人工准备时间？

前三问可做内容与行为研究；第四问需要真实学习者证据。不能拿模型扮演学生、重复生成次数或审查分数回答第四问。

## 2. 先冻结参照，防止自证

### 参照材料

应用/考试目标使用原目标与适用课程范围、教材定理和例题依据；开放目标记录原问题、事实材料、可能立场与取舍，不强求穷尽。材料不能只由生成路线倒推选取，否则未生成的责任会从评价中消失。

每项关键判断应能定位到来源原文、可检查推导/计算，或独立学科审读。用户确认只解决用途和采纳，不承担未知知识的专家认证。来源冲突或题意歧义标为无法判定；不能为凑出标签让另一模型投票。

公开案例 M1—O3 是开发与回归材料。正式比较另选同类而不同内容的保留任务，冻结后不向生成/修复流程提供答案或评分细节。AI 可协助整理，但标签仍须核对依据；若没有可靠标签，就明确只做探索性审读。

### 成本责任

材料准备、参考解答校核及争议审读是实际成本。优先复用公开可靠内容与现有快照，按变化范围复核，不能假设每个学习者身边都有专家，也不能隐去幕后人工时间。缺少专业审读时，计算/逻辑可核的部分仍可推进；整体语义正确性保持未验证。

## 3. 路线与内容比较

| 条件 | 输入与过程 | 用途 |
| --- | --- | --- |
| A 单次基线 | 相同模型、目标、资料集合、输出要求，一次生成 | 测当前复杂流程相对简单调用的净收益；仅隔离研究，不成为人工或无门禁建图入口 |
| B 当前流程 | 冻结当前检索、生成、审查及修复方式 | 基线必须保留首次失败及最终结果 |
| C1 改进材料匹配 | 仅改变片段选择和反馈生成时的依据输入，其他尽量同B | 检查问题相关材料是否减少错误 |
| C2 明确当前条件 | 在C1基础上保留当前题设/参考/条件，隔离旧例子条件 | 单独检查改写与上下文串用 |
| C3 改进帮助选择 | 在可靠材料上采用主报告中的局部策略候选 | 检查教学行为；内容改善和学习收益不能混算 |

这不是要求全量同时运行五套系统；先跑 A/B/C1，只有发现证据支持时才继续局部比较。整个目标仍覆盖路线和教学，不以先做一个子实验冒充完整目标已完成。

固定模型版本、能够控制的生成设置、原始材料、输入目标和总资源上限。任务交错分配运行顺序。将额外资料、换模型、专家先行改稿分别作为不同条件；不能把它们混入C后声称只有策略改进。

同一任务重复运行反映生成稳定性，不能当多个学习者或多个独立学科。所有输出均入分母，包括无效报告、超时和拒绝；同时统计首次可用与修复后可用。并列报告总输入/输出/可取得的推理token、调用数、时延、价格与人工分钟，缺失项明确标明。比较同一总资源上限，也展示质量与实际成本关系；A没有用满预算时不人为补调用。

## 4. 用具体指标代替一个万能分数

| 指标 | 分子/分母或记录办法 | 边界 |
| --- | --- | --- |
| 范围承接 | 有实际教学位置的已确认责任 / 参照范围内责任；逐项解释遗漏 | 不能按关键词出现次数判断已经会教 |
| 前置衔接 | 每个必要前置是否已假设、已教或可就地补；标明具体使用步骤 | 教学顺序不是逻辑依赖；未知不能当已会 |
| 关键内容错误 | 对受审文本记录错误命题、条件、原题与反例/证据；分开严重度 | 局部样本不能估计所有学科错误率 |
| 审查漏判 | 已有可靠标签的错误样例中，未被识别的比例 | uncertain 单列，不混成成功发现或内容错误 |
| 审查误判 | 已有可靠标签的正确样例中，被错误指控的比例 | 不能为了多抓错忽略误伤 |
| 判断覆盖 | 可判定样例 / 全部样例，报告不确定与未覆盖范围 | 拒答很多可能降低漏判但也降低可用性 |
| 更正有效 | 被指出的问题在最终内容中是否解决；是否引入新错；是否真实保存 | 保存成功只是必要技术条件 |
| 帮助适配 | 对实际回应，帮助是否针对问题、可执行、没有虚构错因或无效重复 | 专家偏好只作行为证据，不等于学习增益 |
| 学习表现 | 原始回答、帮助曝光、独立条件、未见任务表现、延迟表现各自记录 | 当堂辅助表现与独立/延迟结果不得合并 |
| 个人效用 | 用户是否能够继续、等待负担、困惑是否得到处理、能否留存和重访 | 满意度不替代内容正确与学习表现 |

评价者先看原目标、材料和候选，尽量不知道方案名称。严重错误的判据和允许的不同表述先确定，评价后不根据想要的结果改标准。争议保留双方依据，不把多数模型一致当外部正确标签。

数学中的有解、等价、条件成立可用适当工具核验；随机试几个数不能证明一般定理。开放探索根据事实忠实、依据范围、替代解释和可修订性审读，可以没有总分。价值选择不同本身不算错误。

## 5. 单用户怎样观察真实帮助

EnglishNode 当前是单用户产品。第一步可做个人探索性比较，不需要伪装成学校规模RCT。

1. 选若干尚未熟悉、难度与目标类型相近的小单元。记录起点，避免在已经学会同一内容后换方案重测。
2. 在不同新单元上交错安排当前方式与候选方式，记录顺序与所花时间。相同主题的练习可能互相迁移，所以仍要承认污染与难度差异。
3. 用户正常学习，可以看答案、跳过和保存；若本人愿意参加独立观察，再事先说明哪段不用帮助。不能把研究测试变成个人保存或完成任务的门槛。
4. 后续使用未曝光、检查同一核心判断的任务。若观察保持，可事先约定例如2—7天的窗口；这个时间只是研究安排，不是新的固定复习算法。没有参加就记录缺失，不算失败或成功。
5. 对开放目标，比较不同材料下的解释与证据使用，允许多个结论；不按接近AI立场评分。可以请可信审读者盲看作品，不能把普通用户满意当专业正确性。

单用户结果主要用于发现明显帮助与损害、选择个人适用方式。它不支持总体人群效应量、显著性或“所有新手均有效”。若以后需要跨用户结论，须另行设计招募、随机化、合适对照、样本量与缺失处理；当前研究没有招募或联系任何人。

## 6. 决策与停止规则

- **发现有证据的重大知识错误或错误反馈**：隔离该候选，定位出处并修订；不让用户确认承担判真责任。修复后重新检查受影响内容，不抹去原失败。
- **审查报告不可用**：记录过程失败，保留原输入和候选；不能把它算成内容错或质量通过。
- **达到资源上限仍有关键未决项**：结束本次尝试并记未解决。停止不等于达标，不能靠重新抽样直到成功后只报最后一次。
- **方案只增加成本，没有可观察改善**：不增加调用或模块；回退该研究假设，保留现有已有效能力。证据不足时写“无法判断”，而非“不存在效应”。
- **部分条件下有改善**：明确是哪类目标、模型、材料和帮助条件，保留失败/误判/未知项；再研究另一类目标，不声称已跨域有效。

没有任意的“80%掌握”或通用综合分门槛。具体任务的接受条件来自它的内容与用途；未证明唯一最优不构成阻断。原产品已有的结构、知识错误、用户确认、版本和安全门继续适用。

## 7. 运行记录模板

下面字段仅是研究记录表，不是拟议数据库schema或新公共API：

```text
run_id / condition / task_id / material_version / model_version
input_goal / assumed_foundations / context_and_reference_ids
raw_output / all_attempts / protocol_failure_or_timeout
scope_findings / prerequisite_findings / factual_findings / evidence
review_verdict / independent_label / label_basis / disagreement
repair_applied / final_content / new_errors / unresolved_items
learner_original_response / help_exposure / selected_help / next_response
measurement_condition / delayed_window / missing_reason
tokens_and_calls / elapsed_time / reported_price / preparation_minutes
```

原始材料和日志若含个人数据或密钥，按项目隔离与保存规则处理，不提交用户数据库、设置文件或凭据。真实AI研究仍使用隔离数据库及临时AI_SETTINGS_PATH；研究计划不是绕过本地API认证的新调用路径。
