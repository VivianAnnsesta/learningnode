# 可恢复的领域路线创建

依据 ADR 0025，替代早期单独任务书确认规格。安全、用户意图、地图版本和来源绑定继续保留。

最小输入为名称与目标；其余可未知。首次保存后 URL 携带 `domainId`，SQLite 保存用户输入、内部任务书与课程方向、完整骨架候选、生成日志及复核状态。刷新只恢复，不重新请求 AI。

AI 规划先形成候选；用户一次审阅具体目标、范围、关键假设、来源状态与完整阶段安排。接受前正式地图不变。接受绑定候选内容、备课依据与 mapRevision，原子 reconcile 稳定 key，并记录用户看到的意图快照。

用户输入改变使相关候选过期，但不会改写正式路线或学习历史。拒绝建议不改路线；过期接受必须返回冲突并重新审阅，不能静默应用。

阶段详情由用户按需展开。生成和修复只改目标阶段，由服务保留课程总目标及其他阶段；合并后继续检查整图与显式 DAG。已开始任务从新安排移除时保留会话、产出及审计入口。

确定性结构和引用错误阻断；语义报告只有有证据的重大教学错误阻断。格式修复不新增课程要求，复核不可用不冒充内容失败或通过；明确风险决策绑定具体草稿和报告。

正式 API 保持 `/api/domains/*`，不存在直接骨架导入或纯人工创建的旁路。验证必须覆盖刷新恢复、意图保真、过期草稿、拒绝不改图、原子接受及局部修复；实际结果见当前状态文档。
