# 统一灵活教学规格（替代早期节点模板）

本规格依据 ADR 0025，覆盖路线节点、个人记录及临时问题。旧九维五段、每段必练与先沉淀再使用练习的合同已退役，旧材料只读。

## 当前合同

- NodeTeachingSession 允许无 domainId/nodeId，使用非空 scopeKey；稳定创建请求复用范围，重新准备属于同一会话。
- TeachingFramework v4 保存当前焦点、用途、范围、核心解释、基础承接与适量部分/步骤。来源支持与知识核对各自保存，不要求固定维度。
- TeachingSegment 按需生成并保存材料版本、真实步骤、可选活动及私有提示/参考依据。开放活动可 solution=null，有评价依据而无唯一答案。
- TeachingInteraction 先保存原输入，再请求反馈；自由提问无需 exerciseKey，作答必须绑定真实会话、segmentId、stepKey、exerciseKey 和 materialVersion。
- 反馈可以选已有活动或提出新材料；服务分配身份并原子提交内容与可执行动作。准备失败不发布空活动；重复请求不重复，迟到结果不能覆盖新材料或新尝试。
- 位置、草稿、已经展示的提示/回应、返回位置和未解问题持久保存。读取不触发 AI，显式重试恢复失败操作。
- 用户随时保存个人记录，独立于作答、结束和节点完成。编辑追加修订，保留真实来源与原上下文，不把 AI 判断变成能力事实。
- 完成由明确动作与预先显示的真实要求校验；答案错误仍可完成尝试。审计与节点状态同事务，普通保存、答疑或复访不反写完成和掌握。

## 核对与历史

核心事实与参考内容接受有界独立核对；确定错误修正文，框架错误产生新框架版本，保留历史材料和输入。核对不可用显示不确定，不得改称“已验证”。

旧格式即便是最新会话也只读，不命中新准备缓存。用户明确沿用摘录可保留原来源；旧活动输入不复制到新题。历史引用包含材料与修订身份。

接口与页面共用 learningSessionService，节点教学 API 只做归属和焦点适配。主要验证是实际活动进入/作答、原输入和版本绑定、曝光记录、幂等与迟到隔离、独立探索返回、个人修订和恢复；实际结果只见当前状态文档。
