# Windows 启动与数据说明

## 已打包桌面

打开 `F:\englishnode\web\dist-electron\win-unpacked\Antigravity.exe`。请保留整个 win-unpacked 目录，单独复制 exe 无法带上本地服务。名称沿用旧安装以继续使用原数据位置，学习页面显示 EnglishNode。

“模型设置”可保存 Provider、地址、模型和密钥，留空密钥保留已有值。保存后新请求生效，关闭重开仍读取同一设置。连接检查只能确认连接；规划、学习和反馈须以实际任务结果判断。

本机已把现有模型配置和经验证的旧库一致性副本接入正式桌面用户目录，并实际打开知识网络、历史及设置确认恢复。项目原数据库与原配置保持不变；可以直接打开程序继续使用。最新迁移数量和验收事实只记录在当前状态文档。

从“学习路线”创建名称和目标，接受具体安排后按需展开阶段；从“当前学习”也可直接输入开放问题。学习空间可提问、进入反馈活动、保存个人内容并选择下一步。“个人知识网络”可检索、修改修订、建立普通跨领域联系和组织多个主题。

## 开发启动

在 `F:\englishnode\web` 安装项目依赖后执行 `npm run dev:electron`。启动器负责数据库、AI 设置和随机本地身份，不需要手工补环境变量。

网页开发执行 `npm run dev`，默认地址 `http://127.0.0.1:3000`；它提供相同的实际保存配置，默认使用开发数据目录。主使用方式是桌面，网页开发不替代 packaged Electron 的权限验证。重新打包执行 `npm run build:app`，失败会停止构建。

## 数据放在哪里

| 使用方式 | 目录 | 文件 |
| --- | --- | --- |
| 打包桌面 | `%LOCALAPPDATA%\Antigravity` | `englishnode-teaching-v2.db`、`ai-settings.json` |
| 项目开发桌面与网页 | `F:\englishnode\web\.electron-user-data` | 同名学习库与设置 |

两个目录含义相同但分别存储；重新构建不覆盖它们。不要把库、设置、密钥或整个用户目录上传 GitHub。密钥不会放进构建产物或页面明文状态。

## 旧内容去向

已安装目录存在 `englishnode.db` 时，首次切换先形成 `englishnode.db.before-teaching-v2.db` 一致性备份，再将副本升级到稳定新库；原文件保留。迁移另留时间戳备份，检查原个人内容、关联和外键，失败保留备份并停止启动，不清空重来。

项目真实 `web/prisma/dev.db` 不直接改写或升级。从本项目构建位置运行的桌面与开发入口可以在“历史内容”发现它并只读查看；携带产品目录去其他位置不会携带这个真实库。当前库中已保留的旧会话也能从“当前学习”打开。

“历史内容”可以翻页读取旧个人内容、教案、材料、输入和反馈。参考解答默认隐藏，明确打开仅供回看。选择“明确沿用为个人摘录”后保存原始来源和快照，重复操作保持同一记录；旧作答不变成新活动证据。

修改路线或归档领域不会删除个人记录、修订或语义关系。移出路线的任务保留当时会话和审计入口；删除主题或联系也保留记录。永久清理另需影响确认。

## 中断与恢复

正常关闭后从“当前学习”继续；保存的输入、材料、帮助、位置和返回入口保持。生成失败或中断保留已完成内容，选择相应重试；读取和刷新不会自动重新研究整课。

遇到启动升级失败，先保留错误日志、原库和备份。关闭应用后，使用相应备份副本恢复到用户目录，并再次通过既有数据库生命周期检查；不要运行 `db push --accept-data-loss` 或删除原库来规避错误。启动日志为用户数据目录的 `backend-error.log`，无需分享包含凭据的设置文件。

本轮实际构建、重启、模型调用、迁移副本和安全交互结果见 [当前状态与逐项验收](../CURRENT_PROGRESS_AND_DIFFICULTIES.md)。自动化或模型复核通过不保证长期学习效果。
