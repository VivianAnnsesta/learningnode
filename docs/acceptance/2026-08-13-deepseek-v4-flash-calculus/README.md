## 人工内容审阅标准

1. **目标与范围覆盖**：路线是否覆盖输入中明确要求的内容及“考研数学一”深度，且不越过排除范围。
2. **前置关系**：DAG 是否让学习者在进入后续阶段前具备真实需要的能力；综合复习是否汇聚全部终端分支。
3. **Module 与问题粒度**：一个问题是否对应可学习、可展开的能力，而不是章节名或多个能力的打包。
4. **可检查结果**：结果是否能通过证明、计算、辨析、方法选择或迁移任务验证，而不只是“能陈述”。
5. **考研可用性**：是否覆盖典型条件、边界、反例、方法选择和综合迁移，而不只是教材目录。
6. **重复生成稳定性**：相同输入是否保持关键范围和主干结构，不发生整片内容随机消失。

## 分轮结论

### 第 1 轮：不通过，可作为大幅修改后的草稿

优点：13 个 Stage 覆盖了单变量、多元、级数、微分方程和空间积分等大类；大多数 Module 都有问题和结果；自动修复确实拆分了部分复合问题。

阻塞问题：

- `综合应用与题型迁移` 没有依赖 `无穷级数`、`多元函数微积分`、`向量代数与空间解析几何`、`曲线积分与曲面积分`。DAG 中 `无穷级数`、`曲线积分与曲面积分` 和 `综合应用` 同时成为终端节点，学习者可以在未完成两条大分支时进入“综合”阶段。
- 多元部分只有二重积分，未覆盖三重积分；曲线/曲面积分部分没有斯托克斯公式。作为“数学一所需”路线，覆盖不足。
- 微分方程只列可分离变量、一阶线性和二阶常系数，方法选择与常见方程类型覆盖偏窄。
- 多个结果仍停留在“能陈述/能列举”，没有给出题型条件辨析或迁移检查。

### 第 2 轮：不通过，是三轮中最接近可用的一轮

优点：覆盖二重、三重积分，级数包含绝对/条件收敛，综合复习通过曲线/曲面积分分支间接依赖了多元与向量分支；总体结构比第 1 轮更紧凑。

阻塞问题：

- `微分方程` 是独立终端分支，`综合应用与题型迁移` 不依赖它，综合阶段仍不是完整汇聚。
- `多元函数微积分` 的 Stage 目标包含多元极限、连续、偏导和重积分，但 Module/问题没有覆盖多元极限与连续；Module 目标还写了全微分，但没有对应关键问题。
- `曲线积分与曲面积分` 的 Stage 目标明确写了斯托克斯公式，但问题节点只覆盖格林公式与高斯公式。这是目标被问题节点漏掉，自动审查未发现。
- 多元极值、条件极值、隐函数求导等重要能力缺失；向量部分缺少曲面/曲线方程，后者只作为非阻塞 warning 被部分识别。

### 第 3 轮：不通过，必须重新生成

优点：单变量微积分部分的分层和可检查结果在三轮中最清楚，函数、极限、导数、积分和级数的主线连贯。

阻塞问题：

- 只有 9 个 Stage，整段缺失微分方程、多元函数微积分、向量与空间解析几何、曲线积分和曲面积分；与输入中的“考研数学一所需”深度明显不一致。
- `综合复习与题型迁移` 只依赖 `无穷级数`，没有依赖另一终端分支 `定积分的应用`，因此“整合各阶段”的目标与 DAG 不一致。
- 相同输入在前两轮生成 13 个 Stage，本轮降为 9 个 Stage，关键范围出现不可接受的随机漂移。

## 跨轮判断

- **结构完整性门有效但不充分**：稳定 key、非空 Module、非空问题、可检查结果和 DAG 无环均通过。
- **语义复审存在系统性漏检**：三轮都由同一模型复审并修复，仍全部留下人工阻塞项；同模型自审不能作为独立验收人。
- **输入本身存在范围张力**：Task Brief 只点名函数、极限、连续、导数、积分及应用，Domain depth 又写“考研数学一所需”，导致模型有时生成完整高数范围，有时收缩成单变量路线。
- **来源不足以约束完整数学一范围**：MIT 18.01SC 是单变量课程；若目标包含多元微积分，至少还需要多元课程或考试大纲级来源。[MIT 18.02 的官方结构](https://live.ocw.mit.edu/courses/18-02sc-multivariable-calculus-fall-2010/pages/syllabus/)明确覆盖向量、偏导/梯度/拉格朗日乘数、二重与三重积分以及 Green/Stokes/Gauss，能直接暴露本轮多元覆盖缺口。
- **可观测性仍有缺口**：Chat Completions 响应 ID 未写入日志，当前只能用内部 `AiCallLog` ID 追踪三段调用。

## 验收决定

- 自动门禁：3/3 通过。
- 人工内容验收：0/3 通过。
- 当前 Provider/model 结论：能稳定产出结构合法、可读的路线草稿，但不能稳定保证考纲覆盖、目标到问题的完整映射和终端分支汇聚；不应自动确认成正式地图。
- 可保留候选：第 2 轮可作为修订起点；第 1 轮需要重连综合阶段并补多元/方程内容；第 3 轮应直接拒绝。

## 下一轮修复门槛

1. 先把 Task Brief 改成无歧义的范围清单，并引入版本化考纲覆盖矩阵；“考研数学一”不能只靠自然语言目标推断。
2. 增加确定性“终端分支汇聚”检查：名为综合/复习/迁移的 Stage 必须依赖除自身外所有终端分支。
3. 增加 Stage goal → Module goal → key question 的覆盖审查，阻止“目标写了斯托克斯/全微分，问题节点没有”的假覆盖。
4. 语义复审使用不同模型或独立规则视角；同模型自审只作为修复建议，不作为最终通过依据。
5. 捕获 Chat Completions 响应 `id` 到 `providerRequestId`，修复后再做同输入 3 次验收。
