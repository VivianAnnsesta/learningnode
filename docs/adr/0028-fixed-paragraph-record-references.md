# ADR 0028: 绑定个人修订的段落引用

状态：已接受，2026-11-08。

## 决策

1. 段落引用沿用个人修订 `sourcesJson` 中的 `kind:"record"`，不增加正文权威、数据库表或迁移。缺省 `selector` 继续表示原有全文引用；显式空值、未知类型和不合法选择器必须拒绝，不能静默退回全文。
2. 新引用仅提交记录身份、修订身份和可选 `{type:"paragraph-v1",start,end,quoteHash}`。偏移是指定修订原始正文的 UTF-16 半开区间；哈希是该区间原文 UTF-8 字节的 SHA-256 小写十六进制。服务端从该记录的该修订取原文，使用共享段落规则验证整数、范围、Unicode边界、完整段落边界与哈希，再生成快照的 `selector.quote`。客户端自报标题、全文或摘录不是事实来源。
3. 段落为由非空白行构成的最大连续文本块，由至少一个空白行分隔。原文中的 LF、CRLF、CR、缩进、段内换行和尾部空格全部保留；空白分隔行不属于选区，不修剪或标准化后计算位置。长段落仍为一个完整段落，不按长度或一句一段拆分。段号仅作显示，不作持久身份。
4. 全文和段落引用可以共存。同一修订中不同位置的段落分别保留，即使摘录文本相同；只有完全相同选择器才去重。所有草稿、按钮禁用、预览、历史和反向引用子项使用统一的选择器身份，不能仅以记录/修订身份覆盖第二个段落。反向引用仍按引用者记录去重分页，保留其全部片段。
   新解析的记录引用在同次保存按该身份去重；既有 retained 或精确匹配的历史快照原样保留，不借去重改写旧修订或删除历史数组项。来源数量仍先受既有输入上限约束。
5. 选择先进入可撤销草稿，明确保存才追加修订。原有 `retained` 来源仍绑定引用者的期望旧修订，原样保留服务器快照；不重新计算旧段落，也不把旧位置套到源记录当前修订。保存冲突不部分写入。快照继续携带所引修订的完整正文，段落预览优先显示固定 `selector.quote`；查看当前版本是独立导航。
6. 段落预览按文本显示，不解析HTML或执行链接，不调用AI，不修改语义关系、课程地图、学习任务或掌握状态。沿用本地认证、来源归属、请求大小、来源数量、不可覆盖修订和安全返回视图边界。

## 验收

共享纯算法检查换行、Unicode、重复段落、范围和哈希；隔离SQLite检查旧全文兼容、多段共存、服务端原文、错修订/错哈希/未知类型拒绝、retained保真和并发原子性。真实页面检查多段选择、草稿撤销、明确保存、重载与反向回看，以及源记录后续修订不移动旧引用。确切结果只记录在当前状态文档，结构通过不等于教学质量或真实学习效果。
