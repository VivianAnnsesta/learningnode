# ADR 0025: 统一学习会话与个人知识网络

日期：2026-10-09。状态：Accepted。依据用户明确授权的《EnglishNode 完整改造任务书》（EnglishNode_Implementation_Plan.docx），本次交付完整能力，不采用数学样本分期或逐批重新授权。

## 决策

旧诊断、节点提示/练习、诊断自动评价及固定路线建议不再提供新生成或写入入口；旧页面只供历史回看，并明确链接统一学习空间。阶段测评和长期学习包的旧写入也退出，既有历史数据与只读接口保留。退役响应仍校验领域或实际对象归属，不调用模型、不制造新证据；普通反馈、练习与下一步只走统一学习会话。领域操作统一表述为归档，保留个人内容、关系和历史，不再提示级联删除。

知识疑点核对可以绑定已有框架、实际材料或已保存反馈，不要求独立探索先生成整课。反馈纠正保留原回答，通过绑定交互身份的补充更正显示；不会覆盖用户输入或把核对结果变成掌握事实。普通反馈的事实主张也适用现有有界检查，不仅检查新增活动；检查应核对分段与端点、计数对象、条件及结论和理由是否相互一致，不硬编码领域答案。

关系候选提示必须列出实际支持的类型以及有效端点，技术校验分别报告身份错误与类型错误。中文描述不得冒充协议类型；修复仍只处理具体结构问题，不能偷偷把未知端点改成另一记录。未请求的参考内容不能通过核对摘要或错误理由提前公开。

针对疑点生成的更正也可能有事实错误，因此更正候选复用已有发布前事实检查，并携带原疑点和实际资料。最多两轮局部纠正；不可用或未解决时保留原文与候选，不将错误检查或不确定性写成认证。更正不成为个人记录，旧输入和原回答不被覆盖。

复核针对当前候选，用户原疑点和此前指控只作定位线索；已执行的局部改动明确传入，不能继续以旧原文断言当前有错。原样或只有空白变化的替换不是有效修正，作为报告协议错误有界修复，不能假装已纠错或推动无意义的事实修复循环。

Windows 桌面保留 Electron 的硬件加速关闭入口，移除互相冲突的强制 SwiftShader、进程内 GPU 及渲染参数。启动和后台错误保存在用户数据目录，重建不丢日志；渲染沙箱、上下文隔离和本地权限边界不变。

历史读取通过固定来源和只读分页覆盖全部内容，不能用截断列表替代历史入口。并存的旧 Word 与 KnowledgePoint 按来源表区分，显式沿用键包含来源、原身份及来源表，避免 ID 冲突静默覆盖。引用快照按实际身份读取，不限于列表第一页。参考答案默认隐藏，用户明确打开历史参考内容不产生新作答或掌握证据。

当前库的独立会话和个人记录同样提供有界分页，返回总数和下一页；主题筛选在数据库中执行，不能先截断再在客户端筛选。后续页保持同一记录身份，读取不调用模型，不制造新的学习事实。

从项目构建目录运行桌面时，允许发现经项目文件识别的原 web/prisma/dev.db 作为只读历史来源；不得直接升级它或把它嵌入产物。已安装的 englishnode.db 仍按用户数据生命周期升级副本，来源选择不接受网页提供的文件路径。

图布局归属只限制视图访问，不决定知识关系的端点或生存。已具有真实 KP 端点的关系不再因布局节点换领域而阻止整理；尚未转换的旧布局关系保持原有保护。知识身份外键、学习节点所属领域与显式前置 DAG 仍必须校验。

复核报告格式失败属于复核服务不可用，不是已证实的课程缺陷。对原报告有界修复，只核对已有要求、真实目标和原文，不增设课程要求；资料不足本身不得冒充伪造来源。有效严重意见不能为通过而删除。修复耗尽保留生成候选、报告原文和不可用状态，用户可以重试或明确核对风险后决定；不得记作复核通过。联网降级仅用于模型缺少该能力，认证或连接失败不得伪装成离线研究成功。

新框架、正文与动态活动发布前针对实际知识主张和内部矛盾做独立核对，引用当前原文后才局部纠正。只处理影响结论的事实错误，不因维度、风格、来源不足或开放问题无唯一答案阻断；最多两轮纠正。核对不可用或证据不足明确保留不确定性，不宣称权威验证。模型原始候选、核对和修正调用分别留存。反馈应读取已有活动的目标与题目，再决定复用或生成，不能只凭身份编号假定相关。

1. 路线项是有范围、目标、必要基础和产出要求的活动入口。名称与目标足以开始；任务书和课程设计是内部备课依据，正式地图审阅合并展示用户意图、假设、依据与差异，不设重复确认关卡。正式变更继续绑定 mapRevision、用户确认及原子替换。
2. 教学按问题组织适量步骤，替换固定九维五段及每段必须练习的契约。保留范围、实际必要知识承接、来源片段、题目/回答/帮助身份、版本和可核对的错误纠正；格式有效不等于知识正确。
3. NodeTeachingSession 同时支持路线、个人记录与独立探索，scopeKey 稳定、requestId 必填。新会话和材料采用新版合同，材料换版不更换会话；旧格式只读，不能命中新生成缓存。回答绑定真实材料、步骤、活动及版本；自由提问无需练习身份。
4. AI 反馈可以选择真实已有活动或提出动态材料。服务分配身份、校验引用，原子保存材料与反馈动作；点击动作必须能执行。技术失败保留原输入与候选，不伪装成已评价，不改写历史。显式重试使用独立尝试令牌，迟到结果不得覆盖新的尝试或材料；框架版本只在成功提交后变化。来源快照只保存当时已展示的参考回应与提示，不能绕过曝光记录。个人记录创建以稳定请求标识和同事务审计防止重试重复。
5. KnowledgePoint 是个人记录的稳定身份；KnowledgePointRevision 是标题、正文、来源的唯一事实来源。用户随时创建和修订，AI 不代替用户接受。节点与记录多对多；主题成员不复制记录。普通跨域关系连接 KP 身份，用户直接建立或明确接受候选，不要求迁移能力认证。
6. 节点仅 available/in_progress/completed，由明确开始/完成命令与 LearningProgress 追加审计同事务写入。保存记录、结束会话与完成节点分开；交付按预先展示的任务要求校验，阅读可本人确认，答错可以完成。掌握、推荐、复习和生成状态不反写节点履历。可改选的主要下一步必须指向真实对象。
7. 地图移除当前计划项时保留任务快照、会话、审计及个人记录，外键 SetNull；领域默认归档。记录、修订和语义关系不依赖画布布局生存。旧积累经确定迁移或只读历史入口可在应用内查看，不以改库名或空库替代升级。
8. 延用现有 Provider、SQLite、Next.js 和 Electron。保持运行期本地 token、Host/Origin、127.0.0.1、来源 URL 安全、用户目录密钥隔离、空白 seed、备份优先迁移及保真/FK门禁。副本验证通过后才使用既有生命周期升级真实库。

## 替代范围

本决策替代 ADR 0016/0017 的固定教案与沉淀前提、0017/0020 的固定维度覆盖、0010 的重复任务书确认、0024 的固定结构执行合同、旧“不提供主要下一步”以及普通跨域必须 WORMHOLE 的产品限制。ADR 0008/0009 的正式改图确认与 AI 规划主路径保留，联网不足允许用户资料，不伪造检索依据。旧文档和代码中的被替代业务约定必须退役；安全及数据约束保持。

## 数据与验收

新增个人修订、节点记录关联与主题成员三张表；现有会话、图节点、边和进度表调整身份与保留关系。来源快照、原输入、历史未知证据保持原含义，未知不转为验证通过。逐项实际结果只记录在 CURRENT_PROGRESS_AND_DIFFICULTIES.md；完整交付包含自动化、真实模型及待用户观察的学习效果三类证据。
