# Course research results must pass a quality gate

Status: Partially superseded by ADR 0009

Network model research output is not trusted just because it used search. For the research-backed creation path, a course design direction or domain map may be labelled verified only after structural validation for source traceability, theoretical skeleton, global explanation, optimization logic, risks, and complete structured content. Cloud and local OpenAI-compatible AI providers remain valid planning providers without a relaxed gate; ADR 0009 supersedes the former manual and direct curated-source paths, while curated material remains valid AI input or evidence. This is a product invariant, not a claim that the current implementation verifies URL reachability or source truth; those checks remain release work. Failed research results must be repaired or regenerated rather than presented as a verified plan.
