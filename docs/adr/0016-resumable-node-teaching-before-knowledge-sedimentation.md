# ADR 0016: 可恢复的节点教学先于知识沉淀

日期：2026-09-06
状态：Accepted；依据用户“设计一下开发节奏，然后执行”的实施授权。实现证据以当前状态文档为准。

## 背景

节点页面已有目标与个人理解确认，但现有 practice 实际生成沉淀后的迁移挑战。新手需要在形成个人知识前获得讲解、示范、练习与反馈。一次 AI 调用日志不足以恢复教学，也不能说明作答是否依赖提示。

## 决策

1. 在正式 Domain/ LearningNode 边界内增加 Node Teaching Session 与 Teaching Interaction。会话绑定目标、Stage 蓝图与课程资料的内容快照；地图版本另行记录。解释、示范、引导和独立练习及参考判据为教学材料，不自动物化 KnowledgePoint。
2. 准备教学由用户触发，使用当前 AI Provider 与有界调用；同一节点和上下文快照复用已准备材料。准备后重新核对上下文，过期响应不得覆盖当前教学。新上下文产生新会话并保留旧记录。
3. 每道题的答案和未查看提示留在服务端；明确查看提示或解答后持久化曝光，再返回相应内容。作答提交先落库，记录当时帮助程度，再请求反馈。请求 ID 防重复，失败可重试；新反馈不得覆盖不同输入。
4. 页面提供解释、示范、练习、提问和个人理解的连续入口，恢复已保存位置、草稿、帮助和交互。写入使用会话 revision 比较，冲突保留本地输入并允许重新加载。刷新不自动触发模型调用。
5. 每个服务和路由核对 URL Domain、LearningNode 与 session 的归属；数据库也约束归属。只使用正式领域 API，保留已有本地认证、URL、迁移与外键门禁。
6. 教学上下文绑定领域用途、任务书、起点说明、范围/排除、深度与输出目标，包含节点 objective/keyQuestion、Stage 对应 checkableOutcome 和已确认 Course Design 的已接地来源片段；来源不足明确标记，模型不得编造引用。材料是 AI 准备、尚未经过独立内容验收的参考，不把来源可达性或自评当正确性证明。
7. 初学教学允许先讲解和示范；检查独立作答时避免未请求的答案披露。用户可自主跳转或查看解答，帮助程度如实记录。任何教学活动都不新增强制通关、唯一下一节点、高阶掌握或沉淀门槛。
8. 现有沉淀后 practice/迁移挑战语义保持，通过独立 teaching API 补沉淀前教学；个人理解仍由用户写下并明确确认，首次状态 seen。

## 备选与代价

仅增加提示/练习按钮无法提供稳定题目、参考答案和恢复。借用 KnowledgePoint 或诊断表会混淆个人知识与教学事实。独立会话需要新增前向迁移与服务，但能把教学职责限制在一个模块内。

首轮复用已有安全抓取片段，不声称已完成教材级全文检索、专业范围校准或教学效果验证。这些分别作为后续课程质量和真实学习实验迭代。
