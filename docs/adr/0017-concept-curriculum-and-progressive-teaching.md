# ADR 0017: 单概念课程与渐进备课

日期：2026-10-04。状态：Accepted（用户明确要求实施教学流程开发方案）。承接 ADR 0013、0014、0016。

2026-10-08：下述严格一概念一节点的粒度约束由 [ADR 0024](0024-teaching-coherence-and-prerequisite-continuity.md) 替代，允许为学习质量合讲相关知识；其余决策保留。

## 决策

1. 新规划协议为 planningVersion=3。一个 LearningNode 只承载一个可独立说明的概念、原理或方法；一个概念可以对应多个 planningQuestionKeys。阶段骨架保存目标覆盖和代表性完整问题，阶段详情仍由用户触发展开。概念复用不是前置依赖，地图确认、DAG、稳定 key 和 mapRevision 规则不变。
2. 入门导引与任务书建议由 AI 生成并持久化，用户仅提供领域也可开始。建议不自动改写已确认目标；明确确认任务书仍是课程研究前提。
3. 教学框架固定九维覆盖、核心定义、范围、贯穿案例及五段教学安排。正文按用户进入的段落生成，跳转不假定之前内容已经学过；生成失败保留框架和已有材料，GET 不触发 AI。
4. 段落材料版本与学习进度独立；交互绑定段落、步骤和材料版本。提示与答案先记录曝光再公开。用户输入先保存，失败可按同一请求重试，过期请求不得覆盖新状态。
5. 资料按实际提取片段引用，采用本地关键词相关性选择。资料缺口允许明确标注的 AI 解释，不允许编造引用。结构校验和独立内容复核属于运行时功能，每次生成最多两次自动修复，不作为权威正确性证明。
6. 反馈仅提供本课解释、示范、对比、边界、回看前置或继续的建议；用户自由决定。教学摘要带原始材料/交互引用，不授予掌握状态。知识仍由用户表达并明确确认后首次沉淀为 seen。
7. 用户选择从新空白库开始。新运行库为 englishnode-teaching-v2.db，由版本化空白 seed 和前向迁移创建；旧库留存、不导入、不改写历史迁移。开发启动和 packaged 启动使用同一库选择规则；重复启动复用新库。原安全和生命周期门禁保持。
8. 本轮不新增测试、不开展专门回归；只进行必要编译/类型检查。功能完成和质量验证分别记录，测试及真实教学效果验证单独开展。

## 代价

分段生成需要持久化任务状态、材料版本和引用；资料缺口必须面向用户表达。新流程不承担旧课程升级兼容，旧教学记录仅保留于旧数据库备份。
