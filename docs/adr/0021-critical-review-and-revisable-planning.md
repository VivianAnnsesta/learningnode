# ADR 0021: 严重缺陷复核与可修订的规划草稿

日期：2026-10-06。状态：Accepted（用户明确要求按已讨论的严重错误标准进行修改和复核）。承接 ADR 0013、0019、0020。

## 决策

1. 规划语义复核仅以有具体依据的严重缺陷阻断：核心知识错误、关键必学内容缺失、必要基础缺失导致课程无法展开、严重偏离确认任务、伪造或冒用来源。阻断意见必须给出目标位置、当前内容证据、违反的既定要求和具体严重后果。密度、表述、适当重复、合理替代顺序和可选补充保留为建议；来源覆盖不足单独标注，不自动等同知识错误。模型意见不等于权威验证。
2. 新复核使用版本化报告契约。服务端校验严重类别、证据字段和实际目标位置；不能由客户端直接给规划赋予通过状态。缺失或无效报告仍按生成失败处理，不将不完整复核默认为通过；历史报告保留原结论，需重新复核才能取得新标准结论。
3. 未确认骨架与整图规划修订可联动修改内容问题、说明要求、九维安排和模块引用；课程总目标的身份与原意、用户确认的任务范围保持不变。允许补充、拆分和合并内容问题，但须保留从原内容到新内容的修订说明，不能靠删除必学要求消除缺陷。修订后重新执行内容覆盖、稳定标识、引用、显式 DAG、版本及既有学习成果保留校验。原文、修订差异、原因和合并结果继续留档。
4. 当前阶段的局部修复仍由服务端原样保留课程总目标、内容登记表、其他阶段和地图版本；超出范围的严重缺陷保留并停止无效局部修复。需要修改登记表时走整图草稿修订，不能由当前阶段顺带改写。此条承接 ADR 0019；本决策修订 ADR 0020 中将骨架和整图语义修订的内容登记表一律设为只读的实现边界。
5. 自动修复只处理严重阻断，不要求消除所有建议。后续复核跟踪原问题是否解决、修改是否引入严重错误；新增严重意见必须依据同一任务要求，不得自行升级范围或深度。问题按类别和目标位置追踪，重复改写不算新问题。最多自动修复两轮；无进展或失败时保留最后结构有效的草稿、未解决意见和调用证据，不以次数耗尽宣称通过。
6. 正式地图仍在原有课程方向、来源状态和完整骨架的联合审查中由用户确认；修订使原摘要绑定的复核失效，不能复用过期通过结论。结构、来源访问、安全与数据生命周期门禁不降低；本轮不新增数据库表或迁移，不改变个人首次 seen 沉淀和自由继续规则。
7. 同一严重缺陷标准适用于九维教学框架和分段正文。框架只检查稳定定义、贯穿案例与完整安排，不要求尚未生成的正文已经给出例题、表格或解答。正文检查当前段落的实质知识、条件、示范和已讲前提；不借复核扩张到后续段落。报告格式错误只修复报告，不能据此重新编写已经结构有效的材料。建议和来源局限单独保留；框架核心定义与范围仍不可由段落修复改写，真实结构或引用错误仍阻断。失败保留实际原因、全部调用关系和最后候选。
8. 当前教案中已存在的内容问题可以关联补充讲解维度；内容问题登记的维度说明必需覆盖，不是禁止其他维度解释同一问题的白名单。仅登记的必需维度计入相应材料覆盖。问题身份、框架段落允许的维度、必需覆盖、步骤及来源引用仍严格校验；不能把合法问题因补充关联不计入必需覆盖而误报成未知问题。
9. 分段生成只填写当前段已安排的步骤，其他段落仅提供目标摘要，不能作为本次可输出的步骤集合。补充解释与示范放在当前步骤内，不擅自新增或带入后续步骤。修复须得到实际/允许的步骤标识及位置差异；无效重复提前停止，仍保留全部失败候选。此边界保持已保存位置、活动和作答对材料的引用稳定。

## 原因与代价

真实微积分规划的复核要求补充分工说明，但修复校验逐字锁定内容登记表，导致同一要求无法执行。另有复核将同一概念的定义、意义和使用当成独立内容必须拆分，容易把可优化空间变成通关条件。固定严重缺陷标准、允许草稿修订并记录原内容承接关系，可保护课程质量和范围，同时让规划能够收敛。服务端只能检查证据结构和引用，语义与学科正确性仍需独立材料核对及后续教学验证。

实现状态、真实运行与验证证据仅记录在 CURRENT_PROGRESS_AND_DIFFICULTIES.md。
