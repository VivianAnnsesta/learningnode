# Confirm course direction and the complete stage skeleton together

## 2026-10-09 后续决定

本 ADR 中冲突的产品约定已被 [ADR 0025](0025-unified-learning-and-personal-knowledge.md) 部分或全部替代。单独课程确认已收敛到一次正式地图接受；用户对具体地图的确认、来源和版本门禁仍有效。 下文保留原决策背景，不能用其旧规则覆盖当前任务书。

Status: Accepted

Updated: 2026-07-15

AI-assisted Domain Map creation uses one planning review before detailed Learning Nodes are generated. The learner reviews the course skeleton, provenance, global explanation, key trade-offs, complete Stage skeleton, explicit Stage prerequisites, and expected Module directions together; course direction and the Stage skeleton become confirmed in the same formal-map transaction. Only then may the learner request expansion of an individual Stage. Curated-source and manual paths may omit research-only fields, but still require the same structural review and confirmation before becoming formal. This avoids both late discovery of a wrong direction and partially confirmed planning state.
