# ADR 0018: 保留 AI 生成原文与失败诊断

日期：2026-10-05。状态：Accepted（用户明确要求保留 AI 返回内容，用于评判生成质量和分析失败原因）。承接 ADR 0013、0017。

## 决策

1. 核心学习任务经统一 AI 执行器调用时，每次实际调用独立记录 AiCallLog。记录包含调用分组与顺序、重试关联、任务/模型/提示版本、提示正文、原始返回文本与 Provider 响应、解析候选、通过校验的结果、具体诊断和失败阶段。原始返回在解析/校验前持久化；后续修复不覆盖前次记录。请求开始记录 pending，未完成的记录保留 pending，读取不自动重试。
2. 原始内容是本地诊断证据，不是 Map Draft、Teaching Framework 或个人知识。保存失败候选不授予正式确认能力，也不放宽来源、目标覆盖、显式前置或用户确认门。
3. 目标覆盖错误一次收集可定位的问题，包含字段路径、Stage/Module/Question key、实际目标与允许目标。确定性校验仍拒绝相同的不合法结构。通用 JSON 修复获得真实失败返回和诊断；保持现有有界重试，不无限重生成或默默修改目标关联。
4. 正式 `/api/domains/:id/ai-logs` 提供分页摘要，`/ai-logs/:logId` 提供单条完整记录；读取校验 Domain 归属，不调用 AI。首版读取入口仅开放课程规划类任务，教学任务的原始教案/提示/答案仍只保留服务端，避免未记录曝光的解答从日志入口泄露。旧摘要记录标明“无原文”，不伪造历史内容。
5. 日志只记录模型输入消息及返回，不记录 Provider 凭据、请求鉴权头或本地 API token。对已知运行时凭据和响应中的凭据字段脱敏；日志在用户本地 SQLite 保存，查看内容按不可信纯文本处理，不渲染 HTML 或自动打开返回的 URL。
6. 数据结构通过新增前向迁移与更新版本化空白 seed 交付。现有日志保留，新增证据字段为空；真实用户库仍仅通过备份优先生命周期升级。日志存储失败不得将无法审计的生成结果当作成功继续使用。

## 原因与代价

真实考研微积分模拟在目标关联校验处失败，但现有日志没有模型原文和具体错误位置，无法确认是缺字段、错引目标还是解析后的变化。完整证据增加本地存储量，调用状态更新也增加少量 SQLite 写入；分页列表不携带整份原文，用户显式打开详情后才读取。结构通过、模型自审与教学准确性仍分别判断。
