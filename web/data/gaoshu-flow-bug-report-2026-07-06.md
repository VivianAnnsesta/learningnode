# 考研数学高等数学全流程模拟：历史快照

> 状态：已被 2026-07-19 的实现与验证证据取代。本文只保留 2026-07-06 的历史结论，不代表当前项目状态；当前事实以根目录 `CURRENT_PROGRESS_AND_DIFFICULTIES.md` 为准。

## 当时发现的问题

2026-07-06 的两次高等数学模拟都停在课程设计质量门之前：任务书与课程设计降级为 fallback，缺少可验证来源，因此没有生成正式 Domain Map。当时还观察到 Provider 连接超时、任务级输出上限不足、模型列表混入非文本模型，以及 Qwen 研究请求未接入明确搜索参数。

这些现象证明质量门能够阻止无来源 fallback 冒充研究型课程设计，但也暴露了 AI 配置、任务策略、模型发现和失败恢复体验的问题。

## 当前替代事实

后续实现和 2026-07-19 验证已经确认：

- Qwen 研究任务会使用 DashScope 搜索参数，并有对应单元测试。
- 当前配置已分别通过 Provider 验证、设置页连接测试和真实课程研究 E2E。
- 领域规划、Stage 展开、节点学习、知识沉淀、知识图谱和诊断路径已完成隔离数据库浏览器验收。
- 当时记录的领域 ID、模型快照、超时值和调参结果只属于那次模拟，不再作为现行配置或产品事实保留。

## 仍然有效的边界

- fallback 不是实际 AI 研究成功，不能使用 `Research-Backed Course Skeleton` 标签。
- 课程研究质量门目前仍主要检查结构和 URL 外形，来源可达性与内容相关性尚未完成。
- AI 不可用时，用户需要明确的配置检查、Provider/模型切换、重试和重新生成路径；2026-07-19 已取消可信来源直接导入和完整人工骨架创建作为独立建图方案。
- Provider 连接成功、普通 AI 任务成功和课程研究返回 `source="ai"` 必须分别验证。
