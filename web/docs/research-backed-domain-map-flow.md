# 领域规划与渐进展开

此文仅解释 [当前顶层设计](../../TOP_LEVEL_DESIGN.md) 和 ADR 0025，不另立规则。

名称与目标 → 内部任务书与课程研究 → 完整阶段草稿 → 一次用户接受 → 逐阶段展开 → 具体差异确认 → 自由选择路线项。

明确应用目标依据代表任务与共同结构组织，开放理解目标依据问题、现象、案例和讨论活动组织。用户意图、假设、依据和顺序理由可看；未知基础不阻断，默认基础不等于掌握证明。

每项承担实际内容责任并说明必要前置与产出。相关概念允许合讲；目录顺序和内容复用不产生依赖。展开和修复限定当前阶段，由服务保留其他阶段与总目标。

正式变更保持 stable key、mapRevision、AI 规划来源、显式 DAG、过期冲突和用户确认。材料备课不改路线；移除任务保留会话和产出，拒绝建议不改变正式地图。

结构引用必须有效。语义复核只按真实原文和既定要求指出严重缺陷，普通建议、目录数量或资料缺口不反复阻断；复核不可用保留候选与原文，不伪装通过。

来源以实际取得内容为准，HTTPS 抓取失败可使用用户粘贴资料；模型无联网能力明确说明。AI 连接、研究、规划、教学与反馈是不同证据。

读取与刷新不重启 AI。路线项三态与审计反映实际任务履历；内容覆盖说明安排与已有材料，不认证掌握。准确状态见 [当前进度](../../CURRENT_PROGRESS_AND_DIFFICULTIES.md)。
