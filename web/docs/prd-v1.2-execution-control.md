# 当前产品执行说明

早期 PRD v1.2 的模板教学和沉淀门槛已由《EnglishNode 完整改造任务书》及 ADR 0025 替代。本说明只解释现有页面职责，当前词汇和行为以仓库权威文档为准。

- 学习路线：名称与目标创建、一次具体路线接受、逐阶段展开和版本化修改，自由选择入口。
- 当前学习：路线或独立会话共用解释、资料、讨论、作答、真实反馈、活动进入、帮助、返回与可进入下一步。
- 个人知识网络：随时保存、检索、修订和来源回看，同一身份多处引用，普通跨域联系与候选接受、多个主题。
- 历史内容：当前旧格式及独立旧库只读回看，分页与明确沿用；不启动旧生成器、不改变当前学习证据。
- AI 设置：实际保存、生效与重启读取，密钥不进入 renderer 明文或构建产物。

保存个人记录、结束会话和完成任务分别操作。节点 available/in_progress/completed，Unit 进展由当前任务计算，Domain 活动或归档。推荐、复访和历史掌握不是新状态。

正式路线与关系需要用户决定，版本和身份由系统校验；当前学习反馈不直接改图。原输入、来源、材料版本、帮助曝光、幂等、迟到隔离、本地权限和迁移保护持续是门禁。

本文件不保存测试数量或完成证据。实际结果与剩余限制统一见 [当前状态](../../CURRENT_PROGRESS_AND_DIFFICULTIES.md)。
